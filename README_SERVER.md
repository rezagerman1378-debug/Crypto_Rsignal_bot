# Early Pump/Dump Scanner — Render

This package is prepared for a long-running Render worker.

## Environment variables
- TELEGRAM_BOT_TOKEN: your BotFather token (keep private)
- TELEGRAM_CHAT_ID: 5343991130
- MIN_SCORE: 80 (conservative)
- MAX_ALERTS_PER_HOUR: 5
- COOLDOWN_MINUTES: 90
- SCAN_SECONDS: 30

## Start command
python scanner.py
